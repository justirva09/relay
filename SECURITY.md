# Security Policy

## Reporting a Vulnerability

Found a security issue in Relay? Please don't open a public GitHub issue.

Report it privately via one of:

- [GitHub Security Advisories](../../security/advisories/new) for this repo (preferred)
- Email: **justirva@gmail.com**

Include steps to reproduce, affected version, and impact if known. You'll get an acknowledgment within a few days.

## Scope

This covers the Relay desktop app itself (Rust/Tauri core, React frontend, CLI, mock server, license verification). Issues in third-party dependencies should generally be reported upstream, but flag them here too if they affect Relay directly.

## Supported Versions

Relay is pre-1.0 and moves fast — only the latest released version is supported. Please update before reporting.
